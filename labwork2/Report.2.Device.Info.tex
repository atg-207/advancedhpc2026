\section{Discussion}
\begin{itemize}
    \item The GPU has 14 SMs with a maximum of 1024 threads per block and a warp size of 32. Block dimensions in future labworks should be selected as multiples of 32 to maximize warp occupancy.
    \item Approximately 3.25 GB of global memory is free, providing sufficient space for input and output image buffers during kernel execution.
\end{itemize}
